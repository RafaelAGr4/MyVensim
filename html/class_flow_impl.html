Detailed Description

Implementacao concreta base da interface Flow. Gerencia o nome, os ponteiros de origem e destino, e implementa todos os metodos da interface, exceto execute() — que permanece abstrato para que cada tipo de fluxo defina sua propria equacao matematica.
